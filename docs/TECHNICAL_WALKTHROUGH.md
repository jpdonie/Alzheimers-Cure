# Technical walkthrough diagrams

Editable source: `technical_walkthrough.tex`

Build from the repository root:

```bash
pdflatex -interaction=nonstopmode -halt-on-error -output-directory docs docs/technical_walkthrough.tex
```

The three pages are deliberately presentation-first:

1. Challenge-aligned end-to-end architecture and the five Apprentice Test answers.
2. Provenance classes, frozen Work Map boundary and pre-save explanation contract.
3. Wandering capture-to-transfer demo sequence.

All clinical-looking content is framed as training/documentation logic. Composite details are labelled and no diagram claims treatment effectiveness.
